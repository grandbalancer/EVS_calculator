# Сводка данных ЭВС

**Сгенерировано `tools/digest.py` из `data/builtin/*.json` и `tests/golden/*.json`. Не править руками:** исправления вносятся в JSON, затем `python3 tools/digest.py`. Источник истины и то, что загружает программа, это JSON; здесь краткий вид для разработки.

Статус: ✔✔ сверено пользователем, ✔ проверено по второму источнику или скану оригинала, ⚠ источники расходятся, ≈ вычислено, … ждёт сверки. Ссылка `книга:л.N` это лист PDF; `стр.N` печатная страница оригинала РПР-69.

## 1. Контракт загрузчика (для `core/`)

- Файлы: `data/builtin/{books,detonators,wires,sources,evs_method}.json`, схема `data/schema/catalog.schema.json`. Пользовательский слой в `%APPDATA%` с той же схемой, id не пересекаются.
- Величина: `{v | min,max | max | min | v,tol, unit, raw}`; нечисловое `{text}`. `raw` только для показа и сверки.
- Перевод в СИ при загрузке: Ом, А, В, м, кг без изменений; `Ом/км` → ×0,001 Ом/м; `мм` → ×0,001 м; `мм²` → ×1e-6 м²; `мкФ` → ×1e-6 Ф; `мДж` → ×0,001 Дж; `кВт` → ×1000 Вт; `А·ч` → ×3600 Кл; `кг/км` → ×0,001 кг/м; `шт`, `пар`, `раз`, `1`, `мес`, `лет`, `°C`, `Гц` без пересчёта.
- Сопротивление линии из провода (`wires`): `cores=2, r_basis=wire` (СПП-2): R = r·L; `cores=2, r_basis=core` (СП-2, ЛТО, ЛТВ): R = 2·r·L; `cores=1` (СП-1, СПП-1, ВМВ): нужны два провода, R = r·(2L). L в км, запас длины по выбору пользователя (`line_margin`).
- Расчётное сопротивление ЭД `params.r_calc`; ток одиночного ЭД `i_calc_single_dc|ac` (для параллельной схемы).
- Источник `kind`: `capacitor_machine`, `magnetoelectric_machine` → проверка по `limits` (схема, ЭД, `max_count`, `max_r`); схемы нет в `limits` → не применяется. `accumulator` → Iист = `i_10h` (кислотные, 6СТ-75/190) или `i_8h` (щелочные), Uист = `u_10h` / `u_initial` / `u_nominal`. `dry_battery` → E0 = `u_initial`, R0 = `r_internal` (верх диапазона), Iист = E0/(2R0) без испытания. `power_station` → `u`, `i_nom`. `mains` → `u`, ток не ограничен.
- Формулы и константы методики берутся из `evs_method.json` по id (раздел 6), не из кода.
