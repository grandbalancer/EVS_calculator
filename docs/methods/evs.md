# Паспорт методики: расчёт ЭВС

Статус: **согласован 2026-11-15** (ответы на вопросы в п. 8). Код решателя пишется по этому паспорту.

Источники: три книги в папке проекта и, по вашему указанию, открытые источники (ГОСТ, учебники, руководства) там, где в книгах пробел. Ошибки книг исправлены, расчёт идёт по верной версии (п. 7).

Источники: Учебник ВЗД 2019, п. 3.3, листы 237–246; Практикум 2023, п. 1.2–1.3, листы 7–14; РПР-69, ст. 66–67 (листы 55–57), ст. 109–112 (листы 95–98), ст. 126–128 (листы 101–104). Везде указаны листы PDF. Числа и правила лежат в `data/builtin/evs_method.json`, эталонные задачи в `tests/golden/evs_cases.json`.

## 1. Цель расчёта

Подобрать источник тока для выбранной схемы ЭВС (Учебник, лист 241; Практикум, лист 7):

1. общее сопротивление сети `Rобщ`;
2. потребный ток `Iпотр`;
3. потребное напряжение `Uпотр = Iпотр · Rобщ`;
4. вывод: обеспечивает ли источник взрыв сети.

## 2. Сопротивление проводов

`r = L · rпр / 1000`, где `L` длина в метрах, `rпр` сопротивление 1 км, Ом (Учебник, лист 241).

Как считается длина (важно, иначе ошибка в 2 раза):

- **Двухжильный провод (СПП-2).** В книге «сопротивление 1 км провода 75 Ом» (лист 214), это обе жилы в петле (2 × 37,5). Длина линии равна расстоянию. Так считает Практикум (листы 9–14). *Подтверждено вами.* Для справки: ГОСТ 2190-77 п. 2.5.4 допускает не более 39,5 Ом/км на жилу СПП-1 и 41,0 Ом/км на жилу СПП-2; в расчёте остаются значения учебника.
- **Одножильный провод (СПП-1, СП-1).** Нужны два провода, длина считается в оба конца (РПР-69 ст. 110 «в оба конца», лист 97; Практикум, задача 2, участковые × 2, лист 12).
- **Кабели табл. 6 РПР-69.** Дано сопротивление 1 км **жилы**. Для двухжильного кабеля сопротивление линии равно 2 · rжилы · L / 1000.
- **Запас длины (слабина)** 10–15 % (Учебник, лист 245; Практикум, листы 9, 12). По вашему решению запас включает пользователь отдельно для магистральных и для участковых проводов, по умолчанию выключен, коэффициент по умолчанию 1,125 (12,5 %). Ход решения показывает, применён ли запас.

## 3. Схемы и формулы

| Схема | `Rобщ` | `Iпотр` (пост. / перем.) | Источник |
|---|---|---|---|
| Последовательная | `rм + rуч + m·rд` | 1,0 / 1,5 А | РПР ст. 67, 110 (листы 57, 97); Учебник 242; Практикум 9 |
| Последовательное соединение групп из попарно-параллельных ЭД | `rм + rуч + mп·rд / 2` | 1,5 / 2,0 А | РПР ст. 111 (лист 98); Учебник 243; Практикум 11 |
| Параллельно-пучковая | `rм + (rуч + rд) / n`, `rуч` одной ветви | `n · i`, `i` расчётный ток одиночного ЭД | Учебник 243–244; Практикум 13; РПР ст. 112 (лист 98) |
| Смешанная (n ветвей по m последовательных ЭД) | `rм + (rуч + m·rд) / n`, `rуч` всех участков одной ветви | `n · Iпосл` (1,0 / 1,5 А на ветвь) | РПР ст. 113, формула (8), оригинал (rpr69s, лист 51, стр. 103); ст. 67. Совпадает с Лукьяновым (4.12)–(4.13) |
| Последовательная с ГЗУ | `rм + rуч + m·(rд + rг)`, `rг ≈ 10 Ом` | как последовательная | РПР ст. 126 (листы 101–102) |

`rд` это расчётное сопротивление ЭД: ЭДП 2,5 Ом, ЭД-8 4 Ом (Учебник, табл. 1.2, листы 51–52). Ток одиночного ЭД: ЭДП 0,5 / 1 А, ЭД-8 0,5 / 1,3 А.

Ступенчатое присоединение ветвей при конденсаторных машинках (РПР ст. 114, стр. 103–104): ветви не дальше 4–6 м друг от друга, не более 4 ветвей, одинаковое число ЭД, сопротивление в пределах табл. 7–9 для параллельного соединения; расчёт как в ст. 113.

Смешанная схема считается по методике, только если во всех ветвях одинаковое число ЭД и равное сопротивление. Иначе работает общий решатель цепи с пометкой «вне методики». При n = 1 формула совпадает с последовательной, при m = 1 с параллельно-пучковой.

## 4. Вывод по источнику

**Конденсаторные и магнитоэлектрические машинки** (КПМ-3, КПМ-1А, ПМ-4, КВП-4/100, КПМ-1, КПМ-2, ПМ-1): таблицы 3.1–3.2 и текст о ПМ-4 считаются для ЭДП, как в Практикуме (ваше решение). Проверяются только два параметра, число ЭД (пар) для выбранной схемы и `Rобщ`, по таблице машинки (Учебник, листы 242, 244; Практикум, лист 8). Если схемы нет в таблице машинки, машинка для неё не применяется (так Практикум решает задачу 2 для КВП-4/100). Напряжение показывается для справки.

**Батареи, аккумуляторы, электростанции, сети** (РПР ст. 115–120, оригинал стр. 104–108; Практикум, лист 8). ПМ-1 только последовательно, R ≤ 290 Ом; КПМ-1, КПМ-2 по своим таблицам; станции и сети по номинальным данным; батареи и аккумуляторы так:

- если ток обеспечен, а напряжение нет: `k ≥ Uпотр / Uист` источников последовательно;
- напряжение источника под нагрузкой `Uист = E0 − I·R0` (9), `R0` измеряется по ст. 92, формулы (1), (2);
- если ток не обеспечен: `n ≥ Iпотр / Iист` источников параллельно (11); для неиспытанных сухих батарей `Iист = E0 / (2·R0)` (12);
- не хватает ни напряжения, ни тока: смешанная батарея `N = m·n` (13); если `Uист` неизвестно: `m ≥ 2·I·R / E0` (14), `n ≥ 2·I·R0 / E0` (15), проверка `Iбат = m·E0 / (R + m·R0/n) ≥ I` (16);
- для аккумуляторов `Iист` это ток длительного режима, как в примере РПР ст. 117 (3СТ-60: 6,0 А): кислотные 10-часовой (табл. 14), щелочные 8-часовой (табл. 13), 6СТ-75 и 6СТ-190 `C10/10` = 6,8 и 17 А. Стартерный ток (6СТ-190 570 А, 6СТ-75 225–270 А по ИР 3012165-0302-94) хранится только для справки;
- источники с током до 1–1,5 А: параллельное и смешанное соединения не допускаются (РПР ст. 67, лист 57);
- батареи 70-АМЦГ и 100-АМЦГ: число батарей по табл. 12 РПР-69 (лист 79);
- осветительные и силовые сети: 110, 220 В постоянного и 127, 220, 380 В переменного тока, любая схема (РПР ст. 96, лист 82).

**ГЗУ с КПМ-1 / КПМ-2** (РПР ст. 128, листы 103–104): `U = 18750 / (rм + rуч + 12,5·m)`. Если `U < 60 В`, машинка применяется без добавочного сопротивления, иначе нужно добавочное не меньше `325 − (rм + rуч + 12,5·m)`.

## 5. Ограничения и проверки входа

- В одной последовательной сети ЭД одного типа и одной партии (РПР ст. 109, лист 96; Учебник, лист 240).
- Ветви параллельно-пучковой сети примерно одинаковой длины (Учебник, лист 244). Если ветви разные, расчёт по методике не делается, только общим решателем.
- От узла безопасности до первого заряда не менее 25 м (Практикум, лист 12).
- ЭДЗД и ЭДКЗ не участвуют в расчёте: электрических параметров в книгах нет.

## 6. Ход решения (CalcTrace)

Каждый шаг: формула буквами, подстановка, результат с единицей, ссылка (книга, лист, статья/таблица). Округление только при показе (Практикум округляет промежуточные значения, из-за этого его ответы расходятся с точными на доли Ома).

## 8. Решения по вопросам (2026-11-15)

1. СПП-2: 75 Ом на 1 км это сопротивление обеих жил. Да.
2. Запас длины: к магистральным и участковым проводам, только по выбору пользователя.
3. Аккумуляторы: `Iист` это 10-часовой ток, как в РПР-69 ст. 117 (сначала был выбран стартерный, изменено после находки оригинала).
4. Смешанная схема: найден оригинал РПР-69 (sappers.org), формула ст. 113 совпала с открытыми источниками (п. 3).
5. Таблицы машинок без типа ЭД: считать как Практикум, то есть для ЭДП.
