# Подрывное дело — расчётчик

Автономное настольное приложение для Windows 7 SP1 и выше. Несколько вкладок с инструментами для расчётов по учебникам взрывного дела. Это не сайт и не часть игры: приложение полностью самостоятельное.

Принцип: **строго по учебникам**. Каждое число и каждая формула привязаны к книге, таблице и листу PDF. Формулы и значения из памяти не используются.

Статус проекта, архитектура и порядок работ: [PLAN.md](PLAN.md). Инструкция для Claude: [CLAUDE.md](CLAUDE.md).

## Вкладки

1. **Расчёт ЭВС** (электровзрывных сетей), делается первой.
2. **Подрывание конструкций** из разных материалов.
3. **Подрывание грунтов и скальных пород.**

Интерфейс на русском, светлая минималистичная тема, практичность важнее оформления.

### 1. Расчёт ЭВС

**Режим «Редактор».** Пользователь рисует сеть на свободном полотне с привязкой к сетке:

- источник тока (подрывная машинка, батарея, электростанция);
- электродетонаторы, вставленные в заряды ВВ, мины или инженерные боеприпасы;
- провода: магистральные, участковые, соединительные. Над каждым проводом отображаются длина и сопротивление, они считаются по типу провода;
- тип сети: последовательная, параллельная, смешанная, включая попарно-параллельные группы (предусмотрены для КПМ-1А и КПМ-3).

Программа рассчитывает сеть и показывает результат:

- общее сопротивление и силу тока в цепи и в каждом электродетонаторе;
- вывод, обеспечивает ли выбранный источник надёжный взрыв сети;
- рекомендации по исправлению, если не обеспечивает: другой источник, схема соединения, сечение проводов.

**Режим «Обратный».** Пользователь вводит параметры сети: источник, тип сети, число и тип электродетонаторов, провода и длины. Программа рисует схему и считает её. Пока данные неполные, схема не строится.

Порядок расчёта по Учебнику ВЗД (п. 3.3): общее сопротивление сети (магистраль, участковые провода, электродетонаторы), потребная сила тока, потребное напряжение, сравнение с возможностями источника, вывод. Точный порядок фиксируется в «паспорте методики» `docs/methods/evs.md` по листам, указанным ниже.

### 2. Подрывание конструкций

Пользователь вводит материал и параметры элемента конструкции. Программа рисует 2D-схему расположения заряда (план и разрез с размерами) и выдаёт потребное количество ВВ или название табельного заряда.

Задание ещё не составлено. Вероятные источники: Учебник ВЗД, главы 4.1-4.3 (дерево, металл, железобетон, здания, фортификационные сооружения; листы 247 и далее), Практикум, разделы 2.1-2.3.

### 3. Подрывание грунтов

Пользователь выбирает вид работ. Программа рассчитывает массу ВВ и все параметры, нужные для этого вида работ, и рисует 2D-схему расположения зарядов в грунте.

Задание ещё не составлено. Вероятные источники: Учебник ВЗД, п. 5.1 «Расчётные формулы зарядов для подрывания грунтов» (лист 286), Практикум, п. 3.1.

## Дополнительные функции

- Сохранение и открытие схем ЭВС (файл проекта).
- Экспорт схем и результатов в PNG и PDF, печать.
- Свои элементы в базе: пользователь добавляет электродетонаторы, провода, источники тока и заряды.
- Каждый результат можно сопроводить ходом решения со ссылкой на таблицу и лист книги. Ядро расчётов отдаёт шаги всегда, показ в интерфейсе подключается позже.

## Как работать с PDF

Книги целиком не читаются. Скрипты в `tools/` достают таблицы и разделы, а читаются только результаты и вырезки нужных листов. Порядок описан в [PLAN.md](PLAN.md), раздел 2.

```bash
python3 -m venv tools/.venv && tools/.venv/bin/pip install -r tools/requirements.txt
tools/.venv/bin/python tools/extract.py all
```

Таблицы CSV лежат в `data/draft/`. Картинки листов, `tmp/review.html` для сверки глазами, тексты разделов и вырезки листов пишутся во временную папку `tmp/`: её можно удалить и пересоздать, в git она не попадает (`.gitignore`). Там же лежат разовые скрипты и скачанные материалы.

## Данные для расчётов

Сверенные с книгами данные лежат в `data/builtin/*.json` (схема `data/schema/catalog.schema.json`). У каждой записи есть ссылка на книгу и лист и статус сверки. Решённые примеры книг для автотестов лежат в `tests/golden/`. Проверка данных: `python3 tools/validate_data.py`. Все данные ЭВС одной страницей: [docs/data_digest.md](docs/data_digest.md). Порядок расчёта ЭВС описан в паспорте [docs/methods/evs.md](docs/methods/evs.md).

## Справочник характеристик

Файл `kharakteristiki-sredstv-vzryvania.xlsx` исправлен по книгам, у каждой строки есть статус сверки, лист «Правки» содержит журнал изменений. Оригинал сохранён в `docs/original/`. Пересборка: `python3 tools/fix_reference_xlsx.py`.

## Технические решения

- C++17, Qt 5.15 (последняя ветка Qt с поддержкой Windows 7), Qt Widgets, CMake.
- Одна 32-битная сборка для Windows 7 SP1 и выше, установщик `setup.exe` (Inno Setup).
- Разработка на Mac, проверка интерфейса на Windows 10/11. Windows 7 для проверки пока нет.
- Ядро расчётов не зависит от Qt и интерфейса.
