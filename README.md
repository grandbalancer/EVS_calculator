# Подрывное дело — расчётчик

Автономное настольное приложение для Windows 7 SP1 и выше: справочник и тренажёр для расчётов по учебникам взрывного дела. Работает без сети, интерфейс на русском, светлая минималистичная тема.

Принцип: **строго по учебникам**. Каждое число и каждая формула хранят ссылку на источник (книга, таблица, лист). Расчёт показывает ход решения: формулу, подстановку, результат и ссылку.

## Возможности

### 1. Расчёт электровзрывных сетей (ЭВС)

**Редактор.** Пользователь рисует сеть на свободном полотне с привязкой к сетке:

- источник тока: подрывная машинка, батарея, аккумулятор, электростанция, осветительная сеть;
- электродетонаторы в зарядах;
- провода: магистральные, участковые, соединительные. Над каждым проводом показаны длина и сопротивление, они считаются по типу провода;
- схема соединения: последовательная, параллельно-пучковая, смешанная, последовательное соединение попарно-параллельных групп.

Программа показывает:

- общее сопротивление сети, потребные ток и напряжение, ток в каждом электродетонаторе;
- вывод, обеспечивает ли выбранный источник надёжный взрыв сети;
- что исправить, если не обеспечивает: другой источник, схема соединения, провод, число источников в батарее.

**Обратный режим.** Пользователь вводит параметры: источник, схему, число и тип электродетонаторов, провода и длины. Программа строит схему и считает её. Пока данных не хватает, схема не строится.

Порядок расчёта описан в паспорте методики [docs/methods/evs.md](docs/methods/evs.md).

### 2. Подрывание конструкций

Пользователь вводит материал и параметры элемента конструкции. Программа выдаёт потребное количество ВВ или подходящий табельный заряд и рисует 2D-схему расположения заряда: план и разрез с размерами.

### 3. Подрывание грунтов и скальных пород

Пользователь выбирает вид работ. Программа рассчитывает массу ВВ и остальные параметры и рисует 2D-схему расположения зарядов.

### Общее

- Сохранение и открытие схем ЭВС.
- Экспорт схем и результатов в PNG и PDF, печать.
- Свои элементы в базе: электродетонаторы, провода, источники тока, заряды. Встроенные данные при этом не меняются.
- Несверенные данные явно помечены в интерфейсе.

## Технологии

- C++17, Qt 5.15 (последняя ветка Qt с поддержкой Windows 7), Qt Widgets и QGraphicsView, CMake.
- Одна 32-битная сборка MinGW для Windows 7 SP1 и новее, установщик `setup.exe` (Inno Setup), без OpenGL.
- Ядро расчётов на чистом C++17, без Qt: тестируется отдельно от интерфейса.
- Данные отделены от кода и лежат в JSON.

## Структура репозитория

```
data/builtin/    встроенные данные: электродетонаторы, провода, источники тока, правила методики (JSON)
data/schema/     схема формата данных
data/draft/      таблицы-черновики, по которым проверяются данные
tests/golden/    решённые примеры из книг: эталоны для тестов расчёта
docs/            паспорт методики, сводка данных, журнал исправлений
tools/           скрипты на Python для подготовки и проверки данных
core/, app/      ядро и интерфейс (появятся на следующем этапе)
```

Все данные ЭВС одной страницей: [docs/data_digest.md](docs/data_digest.md). Найденные в книгах ошибки и их исправления: [docs/errata.md](docs/errata.md).

## Проверка данных

```bash
python3 tools/validate_data.py
```

Скрипт проверяет формат, ссылки на источники, совпадение чисел с черновыми таблицами, актуальность сводки данных и пересчитывает решённые примеры. Он должен проходить без ошибок перед каждым коммитом, который меняет данные.

После изменения JSON сводку нужно пересобрать:

```bash
python3 tools/digest.py
```
